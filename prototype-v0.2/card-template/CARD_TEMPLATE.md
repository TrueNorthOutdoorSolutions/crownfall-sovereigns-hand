# Champion card template (approved)

Approved by Jerian on 2026-10-09. The reference image is `champion-template-bramble.webp` (Set 1 cards 001–003, Bramble ★/★★/★★★).
Every champion card in both sets follows these rules.

## Layout, top to bottom

| Area | ★ Champion card | ★★ / ★★★ Ascension card |
| --- | --- | --- |
| Top-left gem | Green hexagon with the **Command cost** | Gold hexagon with the **Ascend cost** (↑0, ↑1 …). Never a plain number. |
| Name bar | Name (large) and title (small) | Same |
| Top-right | ★ | ★★ or ★★★ |
| Art | Full width | Full width |
| Band under the art | None | **ASCENSION · from [Name] ★** on ★★ cards; **ASCENSION · from [Name] ★★** on ★★★ cards |
| Trait bar | Origin icon + name · Class icon + name · TIER (Roman numeral) | Same |
| Text box, line 1 | Keyword chips with reminder text in italics, e.g. **Bulwark** *(Blocking doesn't turn it sideways.)* | Same. ★★★ cards also show **♛2** at the right of this line. |
| Text box, rules | **Ability name.** then each trigger on its own line, with the trigger word and number in bold (**Block: Scorch 1** the attacker.) | Same |
| Text box, flavour | Italic, centred, in quotes, under a thin rule | Same |
| Stats | Orange shield with ⚔ = Might (bottom-left); blue shield with a shield icon = Guard (bottom-right) | Same |
| Footer | `001/248` · rarity letter · Northern Summit Studios logo · Art: Jerian Latawiec | Same |

## Numbering

- Set 1 is numbered out of **248** (tokens are numbered separately). Set 2 is numbered out of **236**.
- Numbers follow the master list (`MASTER_CARD_LIST_SET1.md`, `MASTER_CARD_LIST_SET2.md`).

## Text rules

- Only use the text in the master list. Every name, number and line is checked by the validator against the game data.
- Keyword reminder text: Charge *(Can attack the turn it arrives.)* · Bulwark *(Blocking doesn't turn it sideways.)* · Ambush *(Attacking a sideways champion, it strikes first.)* · Flight *(Only Flight or Reach can block it.)* · Reach *(Can block Flight.)* · Ascendant *(One per deck.)* · Guardian *(One per deck.)*
- Champions with no keyword start the text box with the ability name.
- Champions with no ability and no keyword (vanilla) leave the rules area empty and show only flavour.
